# 🕹️ Block Runner

Block Runner is a fun, lightweight 2D endless runner game built with HTML, CSS, and JavaScript. The game features level-based themes, jump mechanics, collision detection, sound effects, and dynamic obstacle spawning. It is designed to run smoothly in any modern browser and is perfect for showcasing beginner to intermediate front-end development skills.

---

## 🚀 Features

- **Endless runner mechanics**: Avoid obstacles while your score increases over time.
- **Jump system with gravity**: Press `Space` or `↑` to jump.
- **Collision detection**: The game ends if you hit an obstacle.
- **Level progression**: The background theme changes every 100 points.
- **Sound effects**: Jump, score tick, and hit sounds for game feel.
- **Animated cartoon-style backgrounds**: Themed images for Desert, Ice, and Greenery.
- **Responsive UI with "Press Enter to Start" overlay**.

---

## 🎮 Controls

| Key           | Action               |
|---------------|----------------------|
| `Space` / `↑` | Jump                 |
| `Enter`       | Start / Restart game |
